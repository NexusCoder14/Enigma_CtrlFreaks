# Nivaran

Nivaran is an AI-powered financial closure assistant for grieving families managing a deceased family member's financial matters.

## Project Structure

- `frontend/src/features`: This is where the core logic lives.
- Each team member works inside their assigned `/features/<feature-name>` folder to avoid merge conflicts.
- `frontend/src/components`: Shared components.
- `frontend/src/pages`: Main application pages.
