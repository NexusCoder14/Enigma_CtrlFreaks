# Mock Data for Arjun Mehta

This folder is created for you to drop in images or PDFs of mock documents for "Arjun Mehta".

## How to test:
1. Place image files (.png, .jpg, .jpeg) or .pdf files here.
2. The Nivaran platform's "Document Upload" feature will accept these files.
3. Our backend now fully supports images! It uses an AI OCR (Tesseract) to extract the text from the images you upload, and then sends that extracted text to Groq's LLM to generate the Confidence Ledger and Timeline.
